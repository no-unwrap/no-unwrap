## Focus

I am a published computer vision researcher, and alongside that I'm learning 
to develop secure, safety-critical systems, built to be verified rather than
tested. I'm also exploring secure programming for these systems, looking at 
how memory-safety bugs turn into exploits and how to design code that rules 
them out. Learned components are steadily entering these systems, and the 
models, the low-level systems they run on, and the assurance that they 
behave correctly are usually held by different people. I want to be an 
engineer who can be trusted with all three.

## Philosophy

With systems, I'm drawn to ownership, type-level invariants, allocator
discipline, and compile-time composition. With functional, I'm drawn to
effect tracking, algebraic data types, and totality checking. With
verification, I'm drawn to machine-checked specifications, model checking,
and proofs that hold for all inputs. Some of these I work in, some I'm
learning my way into. All of them shape how I think about building software.
