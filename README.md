My research is in visual saliency and attention, with a focus on how
perception differs across populations that datasets tend to leave out.
Alongside it I'm learning to develop secure, safety-critical systems,
built to be verified rather than tested.

Learned components are steadily entering secure, safety-critical systems,
and the models, the low-level systems they run on, and the assurance that
they behave correctly are usually held by different people. I want to be
an engineer who can be trusted with all three.

## Philosophy

Some of these I work in, some I'm learning my way into. All of them shape how
I think about building software.

With systems, I'm drawn to ownership, type-level invariants, allocator
discipline, and compile-time composition. With functional, I'm drawn to
effect tracking, algebraic data types, and totality checking.
